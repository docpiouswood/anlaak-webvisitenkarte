# Anlaak — Webvisitenkarte

Eine responsive, statische One-Page-Website für die Doom-Death-Metal-Band Anlaak.

Das Repository in Vercel importieren. Es sind keine Build-Einstellungen oder Umgebungsvariablen nötig.
